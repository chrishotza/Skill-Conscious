## Claim-growth rule

The project should not reach 1,000 claims by copying the same idea repeatedly. Each new batch should prioritize:

1. a new source family or historical period;
2. an independently traceable text;
3. atomic claims that can stand or fail independently;
4. explicit contradictions or variant interpretations;
5. source vocabulary before motif normalization.

## Confidence rule

A frequently repeated motif is not automatically true. Promotion requires:

- primary-text support;
- independent source families;
- geographic/historical separation;
- semantic verification;
- alternate interpretation;
- preserved contradiction log.
