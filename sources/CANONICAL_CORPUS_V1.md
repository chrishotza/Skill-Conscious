## Claim discipline

Each claim remains a source-attributed paraphrase. Allowed epistemic classes are:

`EMPIRICAL | THEORY | PHILOSOPHY | PHENOMENOLOGY | CONTEMPLATIVE/TRADITION | SPECULATIVE | PROJECT | BOUNDARY`

Source recurrence is not evidence of truth. Engineering extraction is a project hypothesis
that must survive intervention and adversarial comparison.

## Canonical research pipeline

`SOURCE CLAIM → NORMALIZED MOTIF → SYSTEM COMPONENT → MECHANISM → PREDICTION → INTERVENTION → RESULT → SURVIVES / FAILS / UNRESOLVED`

## System binding

The corpus is now downstream of the canonical system rather than upstream of it. Claims must
map onto observable runtime structures or remain explicitly unresolved. The current central
architecture is:

`boundary → state → present → self-access → attention/value → possibility → intention → selection → action → consequence → transformation → re-entry`
