# Consciousness Component Redundancy v1\n\n## Why this test exists\n\nSingle-component ablation establishes that removing a component changes the\nproposed subjective field. It does not establish that the component is unique.\n\nA second mechanism might compensate for the missing one and restore the same\ndownstream function. If that happens, the architecture has demonstrated\nfunctional redundancy and the stronger claim of unique causal necessity is\nfalse.\n\nThis benchmark therefore asks:\n\n> Can component B replace component A, while A remains absent, and recover the\n> same downstream subjective-field function?\n\n## What counts as substitution\n\nThe target component is genuinely disabled.\n\nThe proposed substitute remains within its native semantic range:\n\n- self_relevance and attention may be increased up to 1.0.\n- boolean mechanisms (binding, continuity, reentry) are only restored to\n  their native ON state and are not given an artificial gain parameter.\n\nNo new mechanism-specific output is injected into the target coordinate.\n\nA substitution is successful only when all of the following hold:\n\n1. the target coordinate remains absent;\n2. subjective unity returns within 0.01 of baseline;\n3. subjective strength returns within 0.01 of baseline;\n4. the same canonical subjective trajectory is selected;\n5. objective scores remain identical;\n6. objective runtime state remains identical.\n\nTherefore a simple rise in one scalar is not enough.\n\n## Experimental matrix\n\nAll ordered pairs are tested:\n\n5 targets x 4 substitutes = 20 directed substitutions\n\nThe default battery uses five independent seeds:\n\n20 x 5 = 100 substitution trials\n\nEvery trial runs the same three conditions:\n\nBASELINE -> TARGET ABLATION -> TARGET ABLATION + SUBSTITUTE\n\nThe world, internal state and objective trajectory signals are matched.\n\n## Interpretation\n\nThere are two possible scientifically meaningful outcomes.\n\n### No successful substitutions\n\nThe proposed components resist replacement by the tested alternatives.\nThis strengthens the claim that their causal roles are functionally\nnon-redundant under the tested regime.\n\nIt does not prove phenomenal consciousness.\n\n### One or more successful substitutions\n\nThe architecture has discovered functional redundancy. The stronger claim\nthat the target component is uniquely necessary must be weakened or refined.\n\nThis is a genuine falsification result, not a test bug.\n\n## Relation to earlier gates\n\nThe redundancy test is deliberately downstream of:\n\n- full-runtime dissociation;\n- single-component ablation;\n- 32-condition factorial sufficiency;\n- unity/strength double dissociation.\n\nThose earlier tests establish that the proposed components matter.\n\nThis test asks whether they matter uniquely.\n\n## Current consciousness standard\n\nA successful architecture is not allowed to stop at generic intelligence,\nprediction, memory, self-description or adaptation.\n\nThe target remains a causal account of a subjectively organized state with:\n\n- unified present;\n- self-related content;\n- temporal continuity;\n- selective access;\n- valence/salience;\n- reentry;\n- action relevance;\n- persistence across self-transformation.\n\nThe project does not equate these architectural results with proof of\nphenomenal experience. It treats them as progressively stronger causal\nconstraints on an executable consciousness hypothesis.\n

## Validated result

The corrected 100-trial battery crossed all 20 directed substitutions across 5 seeds with:

- 0 successful substitutions;
- 100% target-remains-absent;
- 100% matched objective-score control;
- 100% matched objective-processing control.

The earlier red runs exposed contamination in the objective diagnostic. The runtime was then hardened so objective_score uses an immutable matched-objective weight table over explicit candidate signals only. The corrected redundancy battery passed with no successful substitutions.

A dedicated runtime unit test also verifies that large changes in conscious-layer self-relevance and attention leave matched objective_score invariant.
