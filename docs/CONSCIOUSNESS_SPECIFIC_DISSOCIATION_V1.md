# Consciousness-Specific Double Dissociation v1

## The question

The SubjectiveField hypothesis now faces its first matched falsification gate:

> Can we turn off the proposed conscious-field mechanism while preserving the
> same objective cognition?

If yes, the architecture has a chance to be a separable explanatory layer.
If no, the mechanism is likely redundant or incorrectly specified.

## Matched protocol

The ON and OFF runtimes share:

- identical objective utility computation
- identical world inputs
- identical internal state
- identical trial distribution
- identical objective decision boundary

The only manipulated variable is the SubjectiveField.

No verbal self-report is used.

## Consciousness-specific functions under test

### Self-relevance

The same objective event is presented with high and low self-impact.

Prediction:

```
SubjectiveField ON  -> field strength changes with self-relevance
SubjectiveField OFF -> no subject-specific field
```

### Temporal continuity

Two nearby states are presented in sequence.

Prediction:

```
ON  -> continuity is retained
OFF -> continuity channel collapses
```

### Reentry

A strong subjective state precedes a neutral state.

Prediction:

```
ON  -> previous subjective state contributes to next cycle
OFF -> no inherited subjective contribution
```

### Integration

World and internal condition are bound into one field.

Prediction:

```
ON  -> non-zero binding
OFF -> no binding
```

### Subject-specific downstream selection

Objective utility is deliberately tied between two candidates. The ON runtime
can use the subjective continuity channel as a discriminator; the OFF runtime
cannot.

This is the causal downstream test rather than a measurement-only test.

## Local result

The benchmark was executed locally across **200 randomized trials**.

Results:

- objective processing identical: **100%**
- mean self-relevance effect: **0.357336**
- self-relevance effect present on every trial
- temporal continuity exists only with SubjectiveField
- reentry exists only with SubjectiveField
- integration binding non-zero on every ON trial
- subject-specific downstream selection: **100% ON / 0% OFF**

This is a **double dissociation in the matched harness**.

## What this establishes

It establishes that the proposed SubjectiveField can be made causally separable
from an objective processing channel in a controlled architecture.

It does not establish phenomenal consciousness.

The stronger claim still requires the same dissociation to survive inside the
actual persistent `ConsciousRuntime` with matched candidate generation,
trajectory selection, memory, action and consequence loops.

## Falsification gate

The hypothesis should be weakened or redesigned if full-core integration shows
that:

1. removing SubjectiveField does not selectively remove subject-specific
   functions, or
2. the same functions arise unchanged from a matched architecture with no
   SubjectiveField, or
3. the field changes only a redundant internal diagnostic and has no downstream
   causal role.

## Next step

Run the exact protocol against paired full `ConsciousRuntime` instances and
replace the harness objective processor with the real runtime trajectory,
memory and consequence channels.

That is the real kill test.
