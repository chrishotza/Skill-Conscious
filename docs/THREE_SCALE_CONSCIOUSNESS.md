# Three-Scale Consciousness Research Framework

## Core proposal

Skill-Conscious will investigate consciousness at three explanatory scales:

1. **Fundamental consciousness**
2. **Relational consciousness**
3. **Individual consciousness**

For scientific publication, these should be presented as **three research levels** or **scales**, not as three established substances.

The framework is allowed to fail.

## 1. Fundamental scale

### Research question

Could consciousness be a fundamental property of reality rather than something produced only by particular biological systems?

### Scientific status

This is an ontological hypothesis. It is not established fact.

Relevant philosophical models include panpsychist and cosmopsychist positions, but the central scientific problem is not naming a theory; it is specifying a discriminator that could favor one model over another.

### What would count as progress?

A useful fundamental-consciousness paper must do at least one of the following:

- derive a quantitative consequence that differs from non-conscious physical models;
- identify an observational signature;
- specify a controlled comparison between candidate physical models;
- show that the proposed model explains data that competing models do not.

### What does not count?

- coincidence;
- subjective conviction;
- mystical testimony treated as physical measurement;
- semantic similarity between unrelated traditions;
- retrofitting known physics after the result.

### Working hypothesis

> Some physical descriptions may be incomplete if they omit a consciousness-relevant state variable.

This is a hypothesis to test, not a result.

## 2. Relational scale

### Research question

Can consciousness-relevant organization exist primarily in the dynamics of coupling between systems rather than in isolated systems alone?

### Empirical footholds

Relational neuroscience now studies inter-brain dynamics with hyperscanning, including the effects of interactivity and social closeness. This provides a measurable substrate for studying relational organization without assuming that synchronization itself equals shared consciousness.

Key measurable constructs include:

- reciprocal causal influence;
- inter-agent prediction;
- dynamic coupling;
- synchronization beyond common input;
- joint task performance;
- shared attention;
- coupling-dependent changes in individual state;
- resilience after disruption of coupling.

### Working hypothesis

> Under controlled interaction, a coupled system can acquire dynamical properties that cannot be predicted from isolated-agent measurements alone.

The stronger claim — that such properties constitute a shared phenomenal consciousness — remains open.

## 3. Individual scale

### Research question

What organization allows one process to maintain a persistent point of view across time?

### Operational candidates

- causal self-reference;
- persistent self-state;
- self-model participation in future selection;
- temporal continuity;
- memory-dependent identity;
- interoceptive / homeostatic relevance;
- metacognitive calibration;
- trajectory sensitivity to self-model intervention.

### Working hypothesis

> A system's self-model becomes functionally self-referential when intervening on that model changes the system's future state under otherwise controlled conditions.

This is directly testable.

## 4. Cross-scale hypothesis

A candidate nested architecture is:

```text
FUNDAMENTAL
possible substrate-level consciousness
        ↓
RELATIONAL
coupled organization
        ↓
INDIVIDUAL
persistent local point of view
```

This nesting is only a model.

An empirical finding may instead show:

- individual without relational effects;
- relational effects without any fundamental signature;
- no evidence for fundamental consciousness;
- or a different architecture entirely.

The paper program must preserve these alternatives.

## 5. Three-scale measurement matrix

| Scale | Primary object | Strongest current method | Main confound |
|---|---|---|---|
| Fundamental | physical model / observable signature | model comparison + preregistered physical tests | unfalsifiability |
| Relational | coupled system dynamics | hyperscanning / interactive experiments / causal perturbation | common input |
| Individual | self-maintaining agent dynamics | intervention + ablation + longitudinal measures | added memory / computation |

## 6. First empirical sequence

### Individual

Start here because the repository already has executable experiments.

Primary test:

```text
SELF-MODEL INTERVENTION
        ↓
TRAJECTORY CHANGE
        ↓
STATE CHANGE
        ↓
SELF-MODEL UPDATE
```

Required controls:

- identical prompt/input sequence;
- same candidate futures;
- same random seed where applicable;
- self-model intervention only;
- baseline without self-model causality.

### Relational

Second:

```text
ISOLATED AGENT A + ISOLATED AGENT B
             vs
COUPLED A ↔ B
```

Measure whether coupling produces new predictive or dynamical structure after controlling for shared stimulus.

### Fundamental

Third:

Define competing physical models first, then derive discriminating predictions. If no discriminator can be produced, report the limitation instead of manufacturing an empirical claim.

## 7. Scientific language

Use:

> "We test whether..."

rather than:

> "We demonstrate that consciousness is..."

until the evidence warrants the stronger statement.

Use:

> "The system exhibits causal self-reference."

rather than:

> "The system is conscious."

Use:

> "This result is compatible with..."

rather than:

> "This result proves..."

## 8. Why this framework matters

Current consciousness science contains several active, competing theories and increasingly uses head-to-head empirical tests. A 2025 adversarial collaboration directly compared IIT and GNWT, while a 2024 multiscale perspective argued that theories may explain different mechanistic levels rather than simply being mutually exclusive.

The project's advantage should therefore be methodological:

**turn a broad consciousness ontology into explicit cross-scale predictions that can fail.**
