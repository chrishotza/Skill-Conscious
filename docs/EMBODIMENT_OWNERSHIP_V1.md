# Operational Embodiment / Ownership v1

## Purpose

This layer gives Skill-Conscious an explicit operational analogue of embodiment and ownership without claiming that a software boundary is equivalent to a biological body.

The question is:

> Does the persistent process maintain a measurable relation between its own boundary, internal regulation, action history and consequences?

## Runtime state

The runtime-owned EmbodimentState contains:

- boundary integrity;
- interoceptive coupling;
- resource fit;
- ownership coupling;
- action cost;
- revision.

The state is derived from persistent runtime state and authoritative action outcomes.

## Causal pathway

~~~text
PERSISTENT IDENTITY
        ↓
INTERNAL / INTEROCEPTIVE CONDITION
        ↓
RESOURCE FIT
        ↓
ACTION
        ↓
AUTHORITATIVE OUTCOME
        ↓
OWNERSHIP / COST / COUPLING
        ↓
RE-ENTRY
~~~

This makes embodiment an operational relation rather than a prose label.

## Ownership

Ownership coupling increases when the runtime has an action boundary or persistent action history.

The runtime does not infer ownership from a model sentence such as "this action belongs to me".

This preserves the project hierarchy:

RUNTIME EVENT → CONSEQUENCE → INTERNAL STATE

rather than:

MODEL CLAIM → ASSUMED OWNERSHIP.

## Resource fit

An optional persistent resource budget can be configured in the self-model.

The runtime compares observed interoceptive values against that budget and derives a bounded resource fit.

Absence of a configured budget is neutral rather than a deficit.

## Action cost

When an authoritative host outcome contains resource_cost, the runtime carries that observation into EmbodimentState.

This value is not accepted as runtime truth merely because a model frame contains an arbitrary embodiment_state field.

## Geometry coupling

Experience Geometry includes embodiment dimensions:

- boundary integrity;
- interoceptive coupling;
- resource fit;
- ownership coupling;
- action cost.

The geometry therefore captures not only abstract internal state and access regime, but also the operational relation between state, action and consequence.

## Ablation boundary

This v1 layer does not claim:

- biological embodiment;
- body ownership;
- phenomenal mineness;
- substrate equivalence;
- consciousness.

It provides an operational scaffold for testing whether internal regulation and action-consequence ownership add causal organization beyond persistent state alone.
