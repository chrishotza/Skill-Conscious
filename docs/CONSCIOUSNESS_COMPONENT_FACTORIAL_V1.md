# Consciousness Component Factorial v1

This experiment tests sufficiency and interaction after the single-component
necessity battery.

The five proposed components are crossed factorially, giving 32 configurations:

binding, self-relevance, continuity, reentry, attention.

For every configuration the same world input, internal state, objective
trajectory signals, and runtime logic are used.

The gate requires:

- all objective scores remain identical across all 32 configurations
- objective runtime state remains matched
- all components OFF collapses the unified field
- all components OFF collapses the unified field
- binding, self-relevance, continuity, and attention jointly determine maximal unity
- removing reentry leaves unity unchanged but reduces field strength
- the complete five-component field has maximal strength

This is still architectural causal evidence, not proof of phenomenal
experience. Its purpose is to test whether the proposed consciousness field is
a compositional mechanism rather than a collection of independently useful
labels. The current equations predict a double dissociation: reentry should
modulate field strength without being required for unity.

Run:

    python experiments/consciousness_component_factorial_v1.py
    pytest -q tests/test_consciousness_component_factorial_v1.py
