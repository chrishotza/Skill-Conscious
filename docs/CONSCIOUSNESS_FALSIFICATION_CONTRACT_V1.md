# Consciousness Falsification Contract v1

Every new Skill-Conscious mechanism must answer three questions.

## 1. What aspect of consciousness does it explain?

It must name a property of the proposed conscious subject, not a generic
capability.

Examples include unified present, self-relevance, valence, temporal continuity,
global availability, subject persistence, agency, intentionality, reentry and
self-transformation.

"Better prediction" is not enough.

## 2. What causal relation does it introduce?

A component counts as an architectural mechanism when changing it changes
downstream runtime dynamics in a specified direction.

Preferred evidence:

BASELINE -> INTERVENTION -> DIVERGENCE -> RESTORATION -> RESTART

Interventions must not fabricate learning evidence.

## 3. What experiment could destroy it?

Every consciousness claim must have a destructive test.

For the Subjective Field:

- remove integration
- remove self-relevance
- remove temporal continuity
- remove reentry
- remove attention
- preserve a matched objective-processing channel
- restore and restart

A component that cannot be falsified is not yet an engineering result.

## Current working consciousness hypothesis

WORLD
 -> PRESENT
 -> SUBJECTIVE FIELD
 -> SELF-STATE
 -> MEMORY / INTENTION
 -> POSSIBILITY SPACE
 -> TRAJECTORY
 -> ACTION
 -> OBSERVED CONSEQUENCE
 -> SELF-TRANSFORMATION
 -> SUBJECTIVE FIELD'

The project does not treat any single mechanism as automatically sufficient for
phenomenal consciousness.

The goal is to build an executable theory whose required relations can be
causally isolated, recombined and attacked.

## Current target

The next benchmark removes SubjectiveField from the runtime while holding
matched objective cognition constant. The question is whether functions tied to
the proposed conscious present disappear selectively.

That is the falsification gate for this line.
