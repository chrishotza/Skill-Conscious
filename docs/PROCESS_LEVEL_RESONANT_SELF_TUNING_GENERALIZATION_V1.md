# Process-Level Resonant Self-Tuning Generalization v1

This benchmark moves from sequence-pattern generalization to hidden-process
generalization.

Two noisy three-state Markov generators share a uniform stationary marginal but
have opposite cyclic transition dynamics. Twenty independent sequences from
each process are used only for calibration. The resulting lag-field templates
are then frozen.

Evaluation uses 100 fresh sequences per process, 80 states each, with nine
independently sampled attention values per sequence.

## Local result

Executed locally before push:

- resonant alpha accuracy: **100%**
- resonant beta accuracy: **100%**
- generic alpha accuracy: **100%**
- generic beta accuracy: **100%**
- alpha attention -> short-lag weight: **r=0.99868**
- beta attention -> short-lag weight: **r=0.99860**
- alpha attention -> decision margin: **r=0.86137**
- beta attention -> decision margin: **r=-0.81981**
- empirical marginal gap: **0.001125**
- calibration and held-out seeds: disjoint
- all parameters frozen after calibration

The generic controller also performs perfectly. This is therefore not a
performance-superiority claim. The result is that internal attention continues
to modulate temporal integration on trajectories generated by hidden processes
that cannot be distinguished by marginal occupancy alone.

## Mechanistic progression

The benchmark sequence is now:

1. matched temporal-order causality
2. matched generic-controller double dissociation
3. held-out transformation generalization
4. hidden-process generalization

The architectural hypothesis is becoming:

`internal condition -> temporal integration policy -> process-sensitive
resonance -> regime/trajectory selection -> re-entry`

This remains an architectural causal hypothesis, not a demonstration of
phenomenal consciousness.

## Next pressure test

The next experiment should let the runtime infer a process-specific temporal
policy online from its own prediction error and persistence, rather than
receiving separately labeled calibration families. That would test whether
temporal ontology can become endogenous.
