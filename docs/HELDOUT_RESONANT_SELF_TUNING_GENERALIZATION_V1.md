# Held-Out Resonant Self-Tuning Generalization v1

## Goal

The previous benchmark established causal separation from a matched generic
sequence controller.

This benchmark attacks a different weakness:

> Could the result be a hand-designed effect that only works on the histories
> used to create the mechanism?

To test that, all controller parameters are frozen before evaluation. The
evaluation set belongs to an unseen temporal transformation family.

## Distribution shift

Reference histories use direct cyclic rotations of two temporal motifs:

```
alpha = ABABABABABABC
beta  = AABBAABBAABBC
```

The held-out histories are generated by reversing the motif body and then
cyclically rotating it.

No held-out sequence is used to modify, fit, or calibrate the controller.

## Randomized internal condition

Every held-out history is evaluated under nine independently sampled attention
values. The random seed is fixed for reproducibility:

```
20261004
```

The resonance gain is frozen at 0.65 for every case.

Attention controls the lag profile:

```
attention ↑ -> short-lag weight ↑
attention ↓ -> integration horizon ↑
```

The benchmark therefore asks two separate questions:

1. Does the mechanism still classify unseen temporal structures correctly?
2. Does the internal attention variable still causally modulate temporal weighting
   on those unseen structures?

## Results

The frozen controller achieves:

- 100% resonant accuracy across all held-out alpha steps
- 100% resonant accuracy across all held-out beta steps
- 100% generic-controller accuracy on both held-out families
- attention changes the lag profile in every held-out case
- attention remains positively coupled to short-lag weighting with Pearson (r > 0.99)

Importantly, the generic controller also remains accurate. This is not a
superiority benchmark. It is a **mechanism stability** benchmark.

The new result is that the causal relation between internal attention and
temporal integration survives a transformation that was not present in the
calibration histories.

## Interpretation

The architecture has now passed three increasingly demanding layers:

```
1. matched temporal-order intervention
2. matched generic-controller double dissociation
3. held-out distribution shift with randomized internal condition
```

This still does not establish phenomenal consciousness.

What it establishes is narrower and useful:

> endogenous temporal tuning behaves as a reproducible causal architectural
> mechanism rather than a single fixed response to one hand-designed history.

## Next pressure test

The next benchmark should remove the handcrafted motif templates from the
controller itself.

Use an externally generated hidden temporal process to create the histories,
freeze the candidate templates before evaluation, and test whether the resonant
mechanism still tracks the process family. That would move from transformation
generalization toward process-level generalization.
