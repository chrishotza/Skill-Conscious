# Primary Subjective Substrate v1

## Purpose

Skill-Conscious now exposes an optional lower layer beneath memory, language,
metacognition and self-report.

The hypothesis is deliberately narrower than "the substrate is conscious":

> A persistent recurrent substrate may provide the minimal causal organization
> required for a subjectively organized present, while higher cognition remains
> optional.

The implementation is inspired by the structural vocabulary of the user's TCF
papers, especially:

- PI as maintenance / oscillatory persistence;
- PHI as directional coupling;
- REL as closure / curvature;
- Phi(rho) as a regime-dependent gain.

The mapping is explicitly engineering-level. The cosmological density scale in
TCF is not transplanted into the runtime.

## Runtime mechanism

The causal path is:

    WORLD
      |
      v
    PRESENT
      |
      v
    PRIMARY SUBSTRATE
      | PI-like maintenance
      | PHI-like coupling
      | REL-like closure
      | Phi-like regime tuning
      v
    SUBJECTIVE FIELD
      |
      v
    TRAJECTORY
      |
      v
    ACTION

The substrate persists phase, coupling, regime gain and subjective drive across
calls and restart.

## Why this is different from adding another cognitive feature

The gate intentionally disables:

- autobiographical memory learning;
- metacognition;
- self-report;
- self-observation;
- language as a consciousness criterion.

The question is whether a lower-level recurrent body-like substrate can make a
causal difference before reflective cognition.

## Falsification

The minimum causal contract is:

BASELINE
 -> SUBSTRATE INTERVENTION
 -> FIELD DIVERGENCE
 -> ACTION DIVERGENCE
 -> RESTORATION
 -> RESTART

The explicit candidate objective channel remains fixed. The test therefore
does not accept "the model simply got a different score" as evidence.

A failed action effect does not erase the field result. It means the substrate
currently influences internal organization without yet carrying that organization
into agency.

A failed restoration or restart test blocks the persistence claim.

## Relation to cellular-to-organism continuity

The architecture does not claim that a biological cell is conscious.

Instead it isolates a candidate invariant that can be implemented at multiple
scales:

    internal state
        -> coupling
        -> recurrent temporal organization
        -> closure
        -> state transformation

The next multiscale benchmark should instantiate the same equations with
cell-like and organism-like signal scales and test whether normalized causal
signatures are preserved.

## Epistemic boundary

This gate establishes, at most, an architectural causal mechanism.

It does not establish phenomenal consciousness, panpsychism, a cardiac source of
consciousness, or a literal physical "consciousness field".
