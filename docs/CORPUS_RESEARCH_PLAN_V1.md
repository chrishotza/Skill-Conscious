# Consciousness Corpus Research Plan v1

## Objective

Build a traceable 200+ source corpus and convert it into a claim-level, cross-cultural metaphysical model of consciousness.

## Phase 1 — Register

Status: started.

- 325 candidate source records indexed in corpus/SOURCE_REGISTER_V1.md.
- Coverage spans South Asia, East Asia, ancient Mediterranean, Persia, Abrahamic mysticism, Western esotericism, indigenous/comparative traditions, philosophy, phenomenology, science, AI, and heterodox/extended-consciousness programs.

## Phase 2 — Verification

**Status: active. First extraction batch complete: 12 sources / 120 atomic claims.**

The first batch is stored at `corpus/CLAIMS/ANCHOR_CLAIMS_BATCH_V1.md`, with motif assignment summarized in `corpus/CLAIMS/MOTIF_EVIDENCE_SUMMARY_V1.md`.

For each candidate:

1. verify bibliographic identity;
2. locate an authoritative text or scholarly edition;
3. record dating/transmission uncertainty;
4. extract exact consciousness-related passages;
5. split passages into claims;
6. assign claim type and provenance class.

## Phase 3 — Motif normalization

Map each claim to one or more M01–M25 motifs without replacing the source vocabulary.

Examples of forbidden shortcuts:

- Atman ≠ self-model by definition;
- qi ≠ software energy by definition;
- Nous ≠ workspace by definition;
- mystical union ≠ integration metric by definition.

These become possible cross-language mappings only after the source-level interpretation is stable.

## Phase 4 — Convergence

Identify recurring motifs across independent traditions.

For every proposed convergence, record:

- source families;
- geographic separation;
- historical distance;
- textual confidence;
- semantic confidence;
- alternate interpretation;
- whether the recurrence is phenomenological, ontological, metaphysical, or practical.

## Phase 5 — Synthetic Metaphysical Ontology

Produce a versioned ontology that states:

- what consciousness is;
- what self is;
- what mind is;
- what world is;
- how consciousness relates to matter/body;
- whether consciousness is fundamental;
- whether individual consciousness is local or participatory;
- how states and transformations work;
- how death/persistence are interpreted;
- what “ineffable” means operationally.

## Phase 6 — Empirical bridge

For each synthetic principle:

METAPHYSICAL CLAIM
→ OBSERVABLE CONSEQUENCE
→ ARCHITECTURAL MECHANISM
→ MATCHED CONTROL
→ INTERVENTION
→ DOWNSTREAM EFFECT
→ RESTORATION
→ REPLICATION

## Phase 7 — Return to Skill-Conscious

The current runtime becomes the laboratory.

Its existing mechanisms are reclassified by their relation to the synthetic ontology:

- PrimarySubjectiveSubstrate;
- SubjectiveField;
- interoception/homeostasis;
- self-model;
- attention;
- valuation;
- temporal continuity;
- re-entry;
- self-transformation;
- host consequence loop.

No major new subsystem should be added merely because a source mentions it. A mechanism is added when the convergent ontology and an empirical prediction justify it.

## Phase 8 — Publication

Each major version should ship with:

- source corpus snapshot;
- ontology snapshot;
- runtime commit;
- benchmark results;
- failures/null results;
- exact reproduction command;
- DOI/archive record where appropriate.

## Claim extraction milestone

- Batch 1: **120 atomic claims / 12 anchor sources**.
- Current ratio: **10 claims/source** in the first anchor batch.
- Global target: **1,000+ atomic claims**.
- Priority for Batches 2–10: increase independent source-family diversity, especially African, Indigenous, Daoist, Buddhist, Jewish, Christian, Sufi, Greek, Egyptian, Persian, Tantric, and Western esoteric primary corpora.
- Every batch must retain contradiction/variant notes where a motif appears differently across traditions.
- A high-frequency motif is not promoted to the synthetic core until it has independent source-family support and survives semantic review.
