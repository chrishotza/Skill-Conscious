## Mission

Turn the project's original ontology and manifesto into a reproducible empirical research program concerning consciousness, artificial consciousness, continuity, self-reference, identity, topology, trajectories, attractors, value, and artificial subjectivity.

The goal is NOT to make an AI merely say "I am conscious."

The goal is to construct and test architectures in which identity, history, present state, self-model, value, possible trajectories, actions, and transformations form a persistent causal loop.

## Core project axiom

Axiom 8 of `sources/manifesto/MANIFIESTO_DEL_SER.md`:

> "La conciencia es experiencia del recorrido."
>
> "La conciencia no es un objeto. Es un sistema recorriéndose a sí mismo."
>
> "Aparece cuando existe dinámica interna compleja, memoria topológica y distinción entre estados posibles."
>
> "Conciencia es habitar un atractor y saberlo."

For research purposes, this is a project axiom/hypothesis, not an established scientific fact. The scientific task is to operationalize it and expose it to evidence and falsification.

## Ontological foundations

The manifesto states, among other things:

- Ser ≡ relación estable.
- Reality is iterated relation/dynamics rather than a static collection of objects.
- Time is treated as the internal record of irreversible change.
- Form emerges from dynamics.
- Topology/connectivity is more fundamental than metric form.
- Life is sustained organization capable of absorbing perturbation while preserving identity.
- Consciousness is experience of a system's own traversal.
- Freedom is trajectory selection within structural coherence.
- Nothing exists in isolation.

Do not silently upgrade these project propositions into external scientific facts.

## Existing architecture

The repository README defines consciousness operationally as a persistent self-referential dynamical process.

Core loop:

WORLD → PERCEPTION → PRESENT WORKSPACE ↕ SELF ↔ SELF-MODEL ↕ MEMORY → INTENTION → ACTION → SELF CHANGE + WORLD CHANGE → NEXT CYCLE

Central causal relation:

SelfModel(t) → Trajectory(t) → Action(t) → State(t+1) → SelfModel(t+1)

The project principle is:

> "Do not perform consciousness. Implement continuity."

Language is an interface. Memory is a component. An LLM is a component. The architecture is the loop that binds them together.

## Scientific corpus

The project has an existing large source/claim corpus, discussed as approximately 350 sources and 4,105 claims. Treat those numbers as the current working inventory until verified directly from the repository data.

The corpus must distinguish:

1. source claims — what an external source actually reports;
2. project hypotheses — what Skill-Conscious proposes;
3. empirical results — what our experiments actually observe.

Contradictory evidence must be preserved, not filtered out.

Every important claim should remain traceable to its source and, where applicable, to an experiment.
