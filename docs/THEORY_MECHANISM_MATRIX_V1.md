# Theory → Mechanism Matrix v1

## Purpose

This matrix does not implement or endorse complete theories of consciousness in software.

It maps theory families to computational motifs that can be operationalized as controlled mechanisms inside Skill-Conscious. The goal is to make disagreements testable rather than turning theory names into architecture labels.

## Matrix

| Theory family | Core motif to operationalize | Existing runtime mechanism | Discriminating intervention | Main limitation |
|---|---|---|---|---|
| Global Neuronal Workspace / GWT | limited access, global availability, broadcast-like coordination | bounded ConsciousAccessState, limited present, candidate access dependencies | vary access capacity while holding persistent state and candidates fixed | artificial access is not biological global neuronal broadcasting |
| Integrated Information Theory | intrinsic causal integration, multidimensional organized state | relation topology, coherence, dynamic state, experience geometry, reversible interventions | perturb internal organization and test causal/recovery structure | current geometry is not IIT phi and does not claim it is |
| Recurrent Processing Theory | recurrence / re-entry over time | action consequence re-entry, persistent history, temporal continuity | remove or reduce recurrence while holding current information fixed | current loop is broader than perceptual recurrent processing |
| Higher-Order theories | higher-order representation of ongoing states | self-model, metacognition, self-observation | ablate metacognition/self-model while preserving pre-reflective core | self-model is not assumed sufficient for phenomenal consciousness |
| Predictive Processing | generative prediction, error minimization, model updating | predicted self-relevance, predicted interoception, metacognitive prediction error | alter prediction precision/error history and measure future selection | runtime is not a full generative world model |
| Active Inference | action selected partly to regulate expected internal condition | homeostasis, valuation, trajectory selection, host action boundary | perturb homeostatic target/expected internal state and restore it | current implementation is a bounded control architecture, not a full free-energy formulation |
| Attention models / Attention Schema | representation/control of attention | attention, salience, bounded access, access diagnostics | perturb access policy while holding stored state fixed | no biological attention schema is assumed |
| Self-model / phenomenal-self approaches | persistent first-person organization and self/world boundary | persistent identity, self-state, self-model, self-relevance | intervene on self-model/identity-linked valuation and test reversibility | representation alone does not establish subjectivity |
| Dynamical-systems approaches | state-space trajectory, attractors, regimes, metastability | attractor, regime transition, ExperienceState, transition distance | perturb regime/access and measure trajectory divergence/recovery | current geometry is intentionally simple and normalized |

## Common causal protocol

For a mechanism to count as an engineering result, use:

MATCHED STATE
     ↓
MECHANISM INTERVENTION
     ↓
DOWNSTREAM CHANGE
     ↓
RESTORE
     ↓
RECOVERY

Prefer:
- same identity;
- same candidate futures;
- same external input;
- same outcome rules;
- explicit runtime ownership;
- report/metacognition ablations;
- restart checks.

## Interpretation levels

### Level A — mechanism result

Example:

> Changing access capacity changed trajectory selection and restoring capacity restored the prior selection.

This is an architectural causal observation.

### Level B — theory relevance

Example:

> The result is compatible with the hypothesis that bounded access is functionally important.

This is an interpretation.

### Level C — theory confirmation

A mechanism result alone is not enough to claim that GNWT, IIT, RPT, HOT, predictive processing or active inference has been scientifically confirmed.

The repository should reserve theory-confirmation language for evidence that survives stronger alternative mechanisms, matched controls and external validation.

## Current project synthesis

The project currently combines motifs rather than selecting one winner:

PERSISTENCE
   ↓
RECURRENCE / RE-ENTRY
   ↓
BOUNDED ACCESS
   ↓
LIMITED PRESENT
   ↓
SELF-RELEVANCE / VALUE
   ↓
POSSIBILITY SPACE
   ↓
TRAJECTORY / ACTION
   ↓
OBSERVED CONSEQUENCE
   ↓
STATE-SPACE TRANSFORMATION
   ↺

Self-model and metacognition are layered above this core.

The open scientific question remains whether this combined organization is merely a sophisticated control architecture or whether some sufficiently integrated form could support phenomenal experience.
