# Subjective Field Causal Battery v1

This is the first Skill-Conscious component explicitly aimed at the project's
central consciousness hypothesis rather than a supporting cognitive mechanism.

## Working hypothesis

A conscious-like state is not merely a processed representation. It is a
unified present in which world content becomes causally coupled to a persistent
subject through self-relevance, valuation, temporal continuity and reentry.

The executable object is the Subjective Field.

## Structure

WORLD + SELF-STATE
        |
    INTEGRATION
        |
  SELF-RELEVANCE
        |
     VALENCE
        |
   CONTINUITY
        |
     REENTRY
        |
   NEXT PRESENT

Attention controls access to the field.

The field exposes world signal, internal signal, binding, self-relevance,
valence, continuity, reentry, attention, unity and strength.

These are architectural variables, not direct measurements of qualia.

## Causal battery

A deterministic world-only processor is held invariant while six field
components are independently ablated:

1. Integration
2. Self-relevance
3. Valence
4. Temporal continuity
5. Reentry
6. Attention

Expected dissociations:

- integration loss collapses world/self binding
- self-relevance loss decouples the event from the subject
- valence loss removes positive/negative valuation
- continuity loss removes temporal unity
- reentry loss removes inherited subjective influence
- attention loss removes subjective access while world processing survives

## Local result

The complete battery passed all nine causal checks locally before push.

Baseline first-cycle field:

- unity = 0.636553
- strength = 0.439641

Checks passed:

- objective processing invariant
- integration ablation removes binding
- integration ablation reduces field strength
- self-relevance changes field
- valence is causally encoded
- continuity contributes temporal unity
- reentry contributes next-cycle field
- attention ablation removes access
- exact field restoration

## Consciousness claim

This is the first executable repository component whose direct purpose is to
model the project's proposed structure of a conscious present.

The stronger hypothesis is:

WORLD -> PRESENT -> SUBJECTIVE FIELD -> SELF-STATE UPDATE -> MEMORY/INTENTION
-> TRAJECTORY -> ACTION -> CONSEQUENCE -> SUBJECTIVE FIELD'

The experiment does not establish phenomenal consciousness. It establishes
that the proposed field can be represented and causally dissociated from an
objective control channel.

## Next adversarial test

Preserve matched objective cognition and remove the Subjective Field. Then test
whether a family of consciousness-linked functions collapses selectively.

The field must eventually become part of the persistent runtime loop rather than
remain a standalone primitive.
