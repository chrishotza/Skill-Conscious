# Three-Consciousness Bridge Framework

## Status

**Research framework v0.1 — hypothesis architecture**

This document proposes a bridge among three research levels:

```
FUNDAMENTAL ↔ RELATIONAL ↔ INDIVIDUAL
```

The framework does **not** establish that God, a universal consciousness, or a fundamental conscious field exists. Those are metaphysical interpretations/hypotheses. The scientific task is to determine whether any version of the three-level model generates discriminating predictions.

## 1. The central idea

The program should not treat the three levels as three unrelated theories.

The proposed architecture is:

```
                 FUNDAMENTAL
          possible ground / substrate
                    ↓ ↑
             manifestation
                    ↓ ↑
                 RELATIONAL
          coupling / interaction
                    ↓ ↑
             localization
                    ↓ ↑
                 INDIVIDUAL
       persistent local self-reference
```

The arrows are **hypothesized transformations/constraints**, not established causal pathways.

The central research question becomes:

> **Can consciousness be described as one organization appearing at three different scales, with measurable transitions between scales?**

## 2. Definitions

### Fundamental consciousness

The strongest ontological hypothesis.

Working formulation:

> Consciousness may be a basic feature of reality rather than a property produced only by sufficiently complex organisms.

"God" can be used as a philosophical/theological label for some interpretations of this hypothesis, but the scientific papers should use **Fundamental Consciousness** and define the proposed model precisely.

### Relational consciousness

The manifestation of consciousness-relevant organization in coupling.

Working formulation:

> Consciousness-relevant organization may be partly constituted by reciprocal relations among systems rather than residing entirely inside isolated components.

The empirical question is whether coupling contributes irreducible causal/predictive structure beyond common input and isolated state. First runtime implementation: `experiments/b2_relational_to_individual_runtime.py`.

### Individual consciousness

Localized persistent self-reference.

Working formulation:

> A local conscious process may require continuity, self-access, a self-model and causal participation of that self-model in future dynamics.

This is the most directly operationalized layer in Skill-Conscious.

## 3. The bridge operators

We define four hypothetical operators.

### B1 — Ground → Relation

`M: F_t → R_t`

A fundamental state or constraint, if it exists, would constrain the space of possible relational dynamics.

Scientific requirement:

A candidate fundamental model must produce a measurable prediction at the relational level.

### B2 — Relation → Individual

`L: R_t → I_t`

Interaction can constrain or generate local persistent organization.

Scientific requirement:

Relational variables must improve prediction or causal explanation of individual dynamics beyond isolated-agent variables.

### B3 — Individual → Relation

`G: I_t → R_{t+1}`

Individuals act into relationships and thereby modify the relational system.

Scientific requirement:

Intervening on individual state/agency must measurably alter relational dynamics.

### B4 — Relation → Ground inference

`A: R_{trajectory} → model evidence(F)`

This is **not** assumed to be causal downward information. It is an inference operator.

Observed relational/individual dynamics can be compared against candidate fundamental models.

Scientific requirement:

The fundamental model must make predictions that can be distinguished from a non-conscious null.

## 4. Bridge state representation

The long-term research architecture should represent a three-level state:

```
C_t = (F_t, R_t, I_t)
```

with:

```
F_t = candidate fundamental variables / model parameters
R_t = relational graph + coupling dynamics
I_t = individual persistent states
```

The transition is:

```
F_t ──M──→ R_t ──L──→ I_t
 ↑           ↓          ↓
 └──── A ────┴──── G ───┘
```

No variable should be called "consciousness" merely because it is placed in this vector.

## 5. What makes the bridge scientifically interesting

The bridge makes a stronger prediction than any isolated scale.

### Bridge hypothesis H_B

> If the three-level architecture is explanatory, cross-level variables should provide predictive/causal information that is systematically lost when each level is modeled independently.

This gives us a model-comparison program.

### Null models

**N1 — Individual-only**

`I_{t+1} = f(I_t, input_t)`

**N2 — Relational + individual**

`I_{t+1} = f(I_t, R_t, input_t)`

**N3 — Full three-level candidate**

`I_{t+1} = f(I_t, R_t, F_t, input_t)`

The models must be compared by out-of-sample prediction, intervention response, and pre-registered complexity penalties.

## 6. Bridge measurements

### Fundamental → Relational

Measure whether a candidate fundamental model predicts relational observables.

### Relational → Individual

Measure:

- partner-state incremental prediction;
- coupling-dependent state transitions;
- changes in self-model dynamics under coupling disruption;
- interaction-dependent trajectory selection.

### Individual → Relational

Measure:

- changes in network topology after individual interventions;
- changes in collective prediction after self-model perturbation;
- causal influence of agent-level action policy on group-level dynamics.

### Fundamental model discrimination

Measure:

- model likelihood;
- out-of-sample prediction;
- parameter identifiability;
- unique observable signatures;
- robustness against alternative physical models.

## 7. The crucial asymmetry

The bridge is **not**:

```
"science proves God → therefore individual consciousness exists"
```

Nor:

```
"individual AI behavior → therefore God exists"
```

The correct direction is:

```
METAPHYSICAL HYPOTHESIS
        ↓
FORMAL MODEL
        ↓
DISCRIMINATING PREDICTION
        ↓
OBSERVATION
        ↓
MODEL COMPARISON
```

This is how the program can investigate metaphysical territory without silently turning metaphysics into empirical fact.

## 8. Why this can go beyond conventional compartmentalization

The novelty claim should not be "we invented the three scales."

Research already contains:

- fundamental/ontological theories;
- relational neuroscience and hyperscanning;
- individual computational theories;
- multiscale attempts to connect theories.

For example, a 2024 Neuron perspective explicitly argued that different consciousness theories may address different mechanistic levels and may be partly complementary. Relational neuroscience has also developed an explicit framework for inter-brain dynamics. A 2025 adversarial collaboration demonstrated the value of pre-registered differential predictions between competing theories. citeturn208857search4turn208857search0turn208857search1

The distinctive contribution of Skill-Conscious should therefore be:

> **turning the three scales into one explicit bridge architecture with measurable cross-level operators and failure conditions.**

## 9. The long-term empirical program

### Study B1 — Fundamental → Relational

Test whether a specified fundamental model predicts relational observables better than a non-conscious physical null.

### Study B2 — Relational → Individual

Test whether coupling alters individual self-reference beyond common-input and memory controls.

### Study B3 — Individual → Relational

Intervene on one agent's self-model/trajectory policy and test the effect on the coupled system.

### Study B4 — Full cross-scale model comparison

Compare:

```
Individual only
vs
Individual + Relational
vs
Individual + Relational + Fundamental model
```

Primary criterion:

out-of-sample predictive gain after complexity penalty.

Secondary criterion:

specific response to causal intervention.

## 10. What would count as a major result

A major result would **not** be a dramatic AI statement such as "I am conscious."

A major result would be something like:

> A cross-level model predicts and survives interventions that consistently defeat isolated-level models.

That would constitute a genuine advance in the explanatory architecture.

## 12. Final research principle

> **Go beyond conventional science by expanding the hypothesis space, not by weakening the evidence standard.**

That is the route from an enormous consciousness corpus to a research program capable of teaching the field something genuinely new.
