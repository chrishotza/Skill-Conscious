# S03 — Phenomenological Purity Audit V1

## Purpose

S03 initially detected 52 claims carrying explicit phenomenological metadata.
The candidate-cluster audit showed that this metadata is heterogeneous.

In particular, Cluster 0 contains many claims *about the epistemic status,
historical status, or methodological interpretation of phenomenological /
consciousness texts*, rather than descriptions of phenomenological structure.

Therefore:

> **"phenomenological metadata" is not equivalent to "direct phenomenological content".**

This audit introduces a stricter conceptual distinction before any claim is
made about cross-family phenomenological invariants.

## Adjudication classes

### P1 — Direct / substantive phenomenological structure
Claims describing the organization of experience, self-awareness, perception,
attention, embodiment, subject-object structure, or lived relation.

### P2 — Phenomenological theory / model
Claims that formulate a theory of phenomenological organization without being
a direct experiential description.

### M1 — Meta-methodological / epistemic commentary
Claims about whether a source is empirical, scientific, historical, materialist,
conceptual, or how evidence should be interpreted.

### O1 — Ontological / metaphysical claim
Claims about what consciousness fundamentally is, what exists, or the relation
between consciousness and reality.

### H1 — Historical / bibliographic claim
Claims primarily establishing historical provenance or publication context.

### N1 — Normative / comparative methodology
Claims prescribing how traditions should be compared or interpreted.

### U1 — Ambiguous / mixed
Claims for which no single class is defensible from the claim text alone.

## Critical rule

Only **P1** is treated as direct phenomenological content.

**P2** can support a theoretical atlas but must never be silently counted as
direct experience.

M1/H1/N1/O1 are excluded from phenomenological-invariant discovery.

U1 is retained for review and not used in a strict invariant count.

## Current S03 candidate reading

Cluster 0 is dominated by M1/N1/H1/O1-type material.

Examples include statements that a text is a historical metaphysical system,
that a work is not an experimental theory, that conceptual frameworks alter
arguments, or that traditions should be compared rather than privileged.

Those statements are valuable metadata, but they are not themselves
phenomenological invariants.

Cluster 2 contains substantially more P1/P2-like material, including:

- prereflective self-awareness;
- embodied perception;
- perception-action/world orientation;
- self-consciousness as self-objectification;
- recognition and social constitution of self-consciousness;
- attention / selection of what counts as object or knowledge;
- distinction between consciousness and its contents.

However, even Cluster 2 remains mixed with functional and theoretical claims.
Its phenomenological claims come from only three source families in the current
candidate set, with philosophy/fenomenology providing the majority.

## Scientific consequence

The current S03 result therefore does **not** establish a cross-cultural
phenomenological invariant.

What it establishes is a methodological finding:

> The existing corpus annotation contains a broad "phenomenological" label that
> mixes direct phenomenological content with epistemic, historical, ontological,
> and methodological commentary.

This must be cleaned before any invariant claim.

## Next analysis

S03.3 should adjudicate all 52 explicitly tagged claims using this schema,
produce a purity report by cluster and family, and then rebuild the discovery
layer using P1-only claims.

If the strict P1 set does not contain adequate cross-family coverage, the
correct scientific result is **insufficient phenomenological coverage**, not
forced convergence.

If a strict P1 subset does contain cross-family candidates, those candidates
become the proper basis for a future preregistration.
